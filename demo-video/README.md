# Summary

فيديو عرض صامت مدته 89 ثانية. أُضيفت أربع لقطات قصيرة لسير موافقة السائق بعد مشهد لوحة السائق، وصُححت خريطة لوحة الطالب في مشهد البحث. بقي توقيت المشاهد الأصلية الأخرى كما هو.

المواصفات: `MP4 / H.264 / 1920×1080 / 30fps / yuv420p`، دون مسار صوتي.

# Completed

- تصوير الواجهة الحالية من الفرع المحلي، بما فيها اختيار نوع الحساب وخريطة العراق التفاعلية.
- اختيار بغداد ثم المنصور وجامعة بغداد ووقت الوصول الثامنة صباحاً.
- إدخال الاسم والبريد والهاتف وكلمة المرور وتأكيدها، وإنشاء حساب تجريبي فعلي.
- تسجيل الدخول بالحساب نفسه؛ حُذف وقت كتابة بيانات الدخول من المونتاج.
- البحث في لوحة الطالب، عرض خيارين ثم التمرير إلى الثالث، فتح التفاصيل وإرسال طلب محلي بحالة انتظار.
- تسجيل دخول سائق تجريبي عبر خادم المشروع الحقيقي مع قاعدة محلية معزولة، ثم تصوير صفحة طلبات الطلاب.
- إضافة مؤشر وإطارات إبراز ونصوص عربية خارج مساحة الواجهة. الألوان والخطوط والزوايا مأخوذة من ملفات تصميم المشروع.

# Remaining Work

قيود الموقع المعروضة بصدق، وليست تغييرات مطلوبة لإنتاج الفيديو:

- تسجيل الطالب محلي في المتصفح، وليس إنشاء حساب إنتاجي على الخادم.
- البحث في الصفحة العامة يعرض مثالاً واحداً؛ البحث في لوحة الطالب يعرض ستة أمثلة ثابتة. لا يُثبت تطابقاً جغرافياً أو حساباً حقيقياً للنسب.
- أول أربعة خطوط تتبنّى الجامعة المحفوظة، وأول خط يتبنّى المنطقة المحفوظة؛ هذه آلية عرض تجريبي وليست خوارزمية مطابقة فعلية.
- الطلب يُحفظ في جلسة الطالب فقط ولا يصل إلى لوحة السائق.
- صفحة السائق تحتوي بطاقات تجريبية ثابتة؛ زرا القبول والرفض لا ينفذان إجراء. جرى اختبار النقر أثناء الفحص، ولم يُعرض قبول أو تغيير مقاعد في الفيديو.
- حساب السائق المعزول لا يعني أن طلب الطالب انتقل إليه. الانتقال منفصل وموسوم بأنه واجهة أولية.

# Notes

- استُخدمت أصول المشروع الموجودة فقط؛ لا صور مولدة أو قوالب خارجية أو تصاميم بديلة.
- الخريطة والصورة التوضيحية من الأصول الموجودة مسبقاً؛ تفاصيل نسبها وترخيصها موجودة في توثيق التسجيل الأصلي بالمشروع، وتظهر اعتماداتها في الواجهة الأصلية.
- أسماء السائقين والطلاب في البطاقات أمثلة ثابتة من ملفات المشروع. بيانات التسجيل المدخلة وهمية، والبريد يستخدم نطاقاً غير صالح للإرسال. لم تُرسل رسائل أو يُحجز مقعد.
- لم تُقرأ ملفات الأسرار، ولم يُتصل بقاعدة البيانات المشتركة. تُعاد توجيه طلبات المنفذ المتوقع للواجهة إلى الخادم المحلي المعزول فقط؛ لا تُصنع استجابات وهمية.
- اختير وضع المعاينة الموجود في الموقع لمسح الطلبات المسبقة قبل تصوير الطلب الجديد، حتى لا يوحي العرض بموافقة سابقة.
- لا التزام ولا رفع ولا نشر.

# Commands

إعادة التصدير من التسجيل المحفوظ، دون تشغيل الموقع أو الخادم:

```powershell
cd C:\Users\lenovo\Cctrl1\demo-video
npm ci
npm run render
```

تعديل المشاهد ومراجعتها:

```powershell
npm run dev
```

لإعادة التسجيل، شغّل الخادمين في نافذتين منفصلتين ثم نفّذ التسجيل. يلزم متصفح محلي ومكتبات الخادم. الحسابات التالية مخصصة لبيئة التصوير فقط داخل السكربتات.

```powershell
node server.cjs
python local-api.py
npm run capture
npm run render
```

المنافذ المطلوبة: `5199` للواجهة، و`8009` للخادم. لا توقف خوادم أخرى إذا كانت هذه المنافذ مشغولة.

تثبيت متطلبات إعادة التسجيل عند نقل المجلد إلى جهاز آخر:

```powershell
python -m pip install --target python-deps -r requirements-demo.txt
npx playwright install ffmpeg
```

متصفح التسجيل الافتراضي:

`Microsoft Edge`

عند اختلاف موقع المتصفح عدّل إعداد مساره في ملف إعداد التصدير. يعتمد الخط على خط النظام الموجود أصلاً في الموقع:

`Segoe UI`

يمكن تشغيل التصدير والتحقق بسكربت واحد، أو إضافة خيار إعادة التسجيل لتشغيل الخادمين تلقائياً وإغلاق العمليات التي أنشأها السكربت فقط:

```powershell
.\produce.ps1
.\produce.ps1 -Recapture
```

تستخدم لقطة رحلة المنصور إلى جامعة بغداد معاينة خريطة محلية مع نقطتي الانطلاق والوصول وخط واضح بينهما. تعمل هذه المعاينة عند حجب الموارد الخارجية، ولا تدّعي حساب مسار قيادة حي.
